# Digital Resume — Seon-ung YU

Online resume made for the Epitech Web bootcamp mini-project (Day 04-05).

## Structure

```
day04-05/
├── index.html      → content only (HTML)
├── css/style.css   → all the design (CSS, mobile first)
├── js/main.js      → interactive parts (JavaScript)
└── img/            → portrait + photographs (Roland-Garros, Lotus 79, Paris)
```

## Requirements of the subject

| Requirement | Where |
|---|---|
| Clear separation HTML / CSS | `index.html` has no `style`, all design is in `css/style.css` |
| Valid HTML (W3C) | 0 error · CSS also valid (W3C CSS validator) |
| Transitions / animations | hero fade-in, sections appearing on scroll, buttons, menu, flip cards, hangman parts |
| Interactive elements | EN / KO language switch, mobile menu, flip cards, playable mini hangman |
| Contact form | "Contact" section, opens the e-mail application (`mailto:`) |
| Responsive design | mobile first, media queries at 768px (tablet) and 1024px (desktop) |

## Run it

Open `index.html` in a browser. Add `?lang=ko` to the address to open the Korean version.
